# DC Quality Reports — تطبيق أندرويد (APK)

## الفكرة
التطبيق (`index.html`) يُحزَّم داخل ملف APK، فيفتح فورًا ويعمل بدون إنترنت، ويتصل بسيرفر Render للمزامنة فقط. يُبنى الـAPK تلقائيًا على GitHub بدون أي برنامج على جهازك.
معرّف التطبيق الداخلي (`com.pyramids.frozenguard`) وأسماء مفاتيح البيانات **لم تتغير**، فلا تضيع البيانات بسبب تغيير الاسم.

## 1) رفع الملفات إلى GitHub (جذر المستودع، بنفس المسارات)
```
index.html   server.js   package.json
manifest.webmanifest   sw.js
icon-192.png  icon-512.png  icon-maskable-512.png  apple-touch-icon.png
.github/workflows/build-apk.yml
android-app/   (المجلد كامل بما فيه signing/ و res-overrides/)
```
المجلد المخفي `.github`: استخدم **Add file ← Create new file** واكتب الاسم `.github/workflows/build-apk.yml` ثم الصق المحتوى. مجلد `android-app` ارفعه بالسحب والإفلات (يفضّل من الكمبيوتر).
سيعيد Render النشر تلقائيًا ويُنشئ جدول النسخ الاحتياطي بنفسه (ولا يمس البيانات الحالية).

## 2) بناء الـAPK
**Actions ← Build Android APK ← Run workflow**، وبعد نحو 6 إلى 10 دقائق (✓ خضراء) نزّل **DC-Quality-Reports-debug-apk** من Artifacts وفك الضغط.

## 3) تثبيت النسخة الجديدة فوق القديمة — مهم
- النسخ التي تُبنى من الآن تُوقَّع **بمفتاح ثابت** (`android-app/signing/dcq-debug.jks`)، فكل نسخة تالية تُثبَّت **فوق** السابقة وتبقى بياناتها.
- **لمرة واحدة فقط:** الـAPK القديم الذي نزّلته سابقًا وُقِّع بمفتاح عشوائي، فقد يرفض الأندرويد تثبيت الجديد فوقه ("التطبيق غير مثبت / تعارض"). في هذه الحالة:
  1. افتح التطبيق القديم واضغط **مزامنة** (أو أنشئ نسخة احتياطية) ليصل كل شيء إلى السيرفر،
  2. احذف التطبيق القديم، ثم ثبّت الجديد، وأدخل مفتاح المزامنة، فتعود البيانات من السيرفر.
- المفتاح الثابت هذا مناسب للاستخدام الداخلي. لتوقيع أقوى استخدم مفتاحك الخاص (البند التالي)، مع العلم أن تغيير المفتاح لاحقًا يتطلب إعادة تثبيت مرة أخرى.

## 4) نسخة موقّعة بمفتاحك (اختياري)
```
keytool -genkeypair -v -keystore dcq-release.jks -alias dcq -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 dcq-release.jks
```
أضف في **Settings ← Secrets and variables ← Actions** الأسرار: `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS` و`ANDROID_KEY_PASSWORD`، فيُنتج البناء أيضًا **DC-Quality-Reports-release-apk**. احتفظ بالمفتاح في مكان آمن (ضياعه يمنع التحديثات).

## بدون APK: PWA
Chrome على الأندرويد ← ⋮ ← **تثبيت التطبيق**.

## ملاحظات
- تقرير PDF داخل التطبيق الأندرويد يُجهَّز كملف HTML للمشاركة (افتحه بالمتصفح واطبعه/احفظه PDF). Excel والنسخ الاحتياطي يعملان عبر شاشة المشاركة.
- خط Cairo يحتاج إنترنت، وبدونه يظهر خط النظام. الكاميرا (صور الشكاوى والماسح) تحتاج السماح عند أول استخدام.
- إن فشل البناء: افتح الخطوة الحمراء في Actions وابعت لي نص الخطأ.
